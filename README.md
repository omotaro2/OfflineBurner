# フィールドシェルフ

出先のオフライン環境で、保管済みの安定版ファームをブラウザから書き込むためのローカルツールです。家でネットがあるときに安定版をディスクへ保存し、Q508 のような Debian タブレットではそのファイルだけを使います。

棚にあるのは、フィールドで使う次の3つです。

- Cardputer Adv 向け Meshtastic ADV（merged イメージ）
- Cardputer Adv 向け Ratspeak full（Standalone と RNode）
- Heltec WiFi LoRa 32 V3 向け Meshtastic 公式の安定版

プレリリースは取りません。攻撃用のファームウェアは置いていません。棚に固定している安定版はこの3つです。各カードにはサムネイル、GitHub のスター数、その安定版ファイルのダウンロード数を出します。Heltec のダウンロード数は基板単体ではなく、ESP32-S3 版リリース一式の回数です。

Cardputer（無印）のタブと Cardputer Adv のタブでは、ネットがあるときに M5Burner の無印向け公開プロジェクトを一覧できます。Adv は無印の上位互換なので、同じ bin をどちらにも使えます。攻撃向けのファームは出していません。サムネイル下の説明は日本語です。「オフライン用に保管」で bin をこの PC に残します。

アプリは SD から M5Launcher の Install で入れます。カード上のファイル名はプロジェクト名で、置き場所は Launcher の OTA と同じ `downloads` です。全体イメージは、Launcher が読むアプリ部分だけを取り出します。32KB より短いアプリは、Launcher がインストール前に見る位置まで埋めてから置きます。Launcher を消して別のファームで上書きはしません。

Launcher が消えたときだけ、「M5Launcher（復旧）」を保管して「復旧用に書き込む」を使います。無印と Adv は同じ公式 bin です。この書き込みは今の Launcher と、そこから入れたアプリを消します。

画面はタブで分かれています。安定版は棚のファーム、プロジェクトは公開一覧、保管はチェックした項目だけをカードへ送る場所、カードは `downloads` の一覧です。カードと一致している項目は緑、新しい版がある項目はオレンジ、カードの方が新しい項目は青、ファイルがない項目は赤です。

ふだんの送信は、Launcher の USB モードでこの PC とつながっていることを前提にします。無印または Adv で Launcher を開き、メニューの USB を選びます。挿さったカードが「Launcher SD」として見えると、保管タブでチェックした bin だけを `downloads` へ直接書きます。カードタブでは、チェックした bin を削除できます。書き込みが権限で止まったときは、今のユーザーでカードを開き直してからもう一度書きます。送り終わったら USB を終了し、Launcher の SD から `downloads` を開いて、プロジェクト名の bin を Install します。Heltec V3 の Meshtastic だけは、これまでどおり全消去して書き込みます。

## 手元のコピーを更新する

`data/cache/` に保管した bin はそのまま残ります。起動中の開発サーバは止めてから、次を実行します。

```bash
git pull
npm install
npm run dev
```

## 使い方

家のネットに繋がっている状態で入れます。

```bash
npm install
npm run dev
```

Chromium で http://127.0.0.1:43127 を開きます。

1. 「安定版をまとめて保管」を押す。ファイルは `data/cache/` に残ります。
2. 出先では同じコマンドでこのアプリを起動する。ネットが無くても、保管済みのカードから「オフラインで書き込む」が使えます。
3. 家に戻ったら、もう一度「安定版をまとめて保管」か、各カードの「安定版に更新」を押す。公開中の安定版と保管済みの版が違うときだけ、更新ボタンに変わります。

書き込みは Web Serial を使うので、Chrome か Edge で開きます。Firefox では保管はできて、書き込みはできません。

## Q508 / Debian

ユーザーを `dialout` に入れて、一度ログアウトします。

```bash
sudo apt install python3-venv
sudo usermod -aG dialout $USER
```

このアプリ自体に Python は不要です。ポートの権限だけ足します。書き込み中は、このページ以外のブラウザタブとシリアルモニタを閉じます。

Cardputer Adv は、側面スイッチを OFF にし、G0 を押したまま USB を挿してから離します。Heltec V3 が応答しないときは、PRG を押したまま RST を一度押します。どちらの書き込みもフラッシュを全消去するので、端末内の設定と履歴は消えます。

LoRa キャップや Heltec は、起動して送信する前にアンテナを付けます。Cap LoRa-1262 の技適は 922.0〜923.4 MHz、空中線電力 1.5〜5.0 mW です。
